# שתי דרכים להיכנס לספרייה

אבות טיפוס אינטראקטיביים בעברית/RTL, עם ספרייה בפיקסל ארט ופקדים נקיים. נתוני הדוגמה, איורי ה־SVG והטקסטים מקוריים ונוצרו עבור העבודה הזאת. אין תלויות, שירותי צד שלישי, גופנים חיצוניים או שליחת קבצים.

## פתיחה

אפשר לפתוח את `index.html` ישירות בדפדפן. הקישורים משם פותחים את שתי החלופות; אין צורך בהתקנה או בשרת.

לחלופין, משורש הענף:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/design/preview_pixel_library.ps1 -Port 8817
```

פתחו `http://127.0.0.1:8817/`. השרת מקומי וקורא רק את קובצי תיקיית אבות הטיפוס. בחרו פורט אחר אם הוא תפוס. Ctrl+C מפסיק אותו. אין שינוי קבוע במדיניות הרצת הסקריפטים.

## החלופות

- **א — חדר הקריאה (`a.html`):** מתחיל בספרייה, ניווט קבוע מימין, מסגרת ירוקה כהה ועץ אגוז. תרגום חדש מרכז את הבחירות על שולחן אחד; מתאים כהשערה לעבודה חוזרת.
- **ב — שולחן הקטלוג (`b.html`):** ניווט עליון, קלף בהיר וכרטיסי קטלוג. תרגום חדש מלווה בשלושה צעדים: ספר, בחירות, סיכום. מתאים כהשערה לכניסה ראשונה.

שתיהן כוללות ספרייה וחיפוש/סינון; בחירת קובץ או דוגמה; פרופיל ושפת יעד; מחוון בדיקה עם בחירה ישירה; מחוון תקציב ושדה מדויק; אפשרויות מקור/סריקה/גופן/מונחים; אישור; התקדמות מדומה; השהיה והמשך; מקור מול טיוטה בעברית או באנגלית, עריכה ומעבר מקטעים; הורדת דוגמה ב־HTML או טקסט; למידה בשש שפות, מאמץ, פרקים, פירוש וקריאה; העדפות והסבר חיבור.

## מסלול השוואה של חמש דקות

1. חפשו ״צרפתית״ בספרייה, ואז נסו חיפוש ללא תוצאות ואיפוס.
2. פתחו תרגום חדש ובחרו ״ספר לדוגמה״. שנו לפרופיל ספרותי, בדיקה מעמיקה ותקציב $7.25. בחלופה ב עברו בין שלושת הצעדים.
3. התחילו הדמיה, השהו והמשיכו. אפשר לדלג לתוצאה לדוגמה.
4. ערכו מקטע, שמרו ועברו קדימה ואחורה. הורידו דוגמה.
5. פתחו למידה, בחרו ערבית ספרותית, מאמץ ופרק. לחצו על המילה הזרה ועל ״קראתי את הפרק״. במובייל בחירות הלמידה מתקפלות, כדי לפנות מקום לקריאה.
6. בדקו Tab, חצים במחוון, Escape בדיאלוג, ותצוגה צרה. נסו לצמצם את איורי הספרייה בהעדפות.

## גבולות ההדגמה

בחירת קובץ משתמש בודקת שם, סיומת וגודל בלבד; תוכנו לא נקרא. אין תרגום, OCR, ספק, אומדן עלות אמיתי, יצירת שיעור, חיבור API או שמירת סודות. ההתקדמות היא שעון הדמיה ונמשכת גם בעת ניווט; פרקי הלמידה חוזרים על אותו טקסט לדוגמה. אחוז המאמץ ממחיש את הפקד ואינו מחליף אחוז מילים מחושב. ההורדה היא HTML/טקסט מקורי לדוגמה עם העריכות שלכם, ולא PDF/EPUB מתורגם. שמירת עריכה אינה אישור מחקרי. כל המצב בזיכרון החלון ונמחק ברענון. נתוני המדף נשארים דוגמאות קבועות; אין ניהול ספרייה מתמשך או תור משימות.

השלמות כאן היא של זרימות התנסות ופריסות מתחרות, לא של חיבור למנוע המוצר. בחירת עיצוב, בדיקות עם משתמשים וחוזה שילוב ל־backend נדרשים לפני שילוב עתידי.
