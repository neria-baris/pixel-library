# ספרים עם אופי — מפתח, מודלים וכריכות

15.10.2026 · המשך ליטוש של חלופה א בלבד, בענף `design/pixel-library-prototypes`.

## המפתח בכותרת

בעקבות הבהרת המשתמש, המפתח הוא **איור של מצב המפתח**, כמו בממשק המוצר הקיים, ואינו בקשה להוסיף טופס להזנת סוד. הוא מופיע בכותרת בכל מסך, לצד המודל הנבחר, גם במובייל:

- אפור עם ״אין מפתח״ כשאין מפתח זמין.
- ירוק עם ״זמין להרצה״ כשיש מפתח זמין אך אינו שמור במחשב.
- זהוב עם ״שמור במחשב״ וסימון נוסף כשיש מפתח שמור.

לחיצה פותחת את ״צרור המפתחות״, עם פירוט לפי ספק. כמו במוצר הקיים, החיווי הראשי מסכם את כלל הספקים; פרטי המודל והבחירה מציגים בנפרד את מצב הספק שלו. מפתח שמור אינו אימות של חיבור תקין. כאן כל המצבים הם **המחשה בלבד**: כפתורים מחליפים מצב דוגמה, בלי קריאת מפתחות המוצר, איסוף סודות או אחסון קבוע.

מקור הסמנטיקה: `renderKeyIndicator` ו־`keySource` ב־[ui.js](../../../scholarly_translation/ui/ui.js), ואיור המפתח בכותרת [ui.html](../../../scholarly_translation/ui/ui.html). האיור החדש נבנה בפיקסלים בקוד SVG מקומי.

## בחירת מודלים

הכפתור לצד המפתח פותח בחירה ישירה: תפקיד, סינון ספק וכרטיסי רדיו של מודלים. אין תפריט נפתח. קיימים מתרגם, בדיקת מקטעים ובדיקת פרקים; שני תפקידי הבדיקה יכולים להשתמש במודל המתרגם או בבחירה עצמאית. ״שמירת הבחירה״ מחילה את הטיוטה; ביטול, סגירה ו־Escape משאירים את הבחירה הקודמת ומחזירים מיקוד לכפתור. סינון הספק אינו משנה בחירה קיימת.

המתרגם מופיע בכותרת ובסיכום התרגום. חלון האישור מציג את כל שלושת התפקידים. שמות הדוגמאות נלקחו מ־[קטלוג הפרויקט](../../../scholarly_translation/models/catalog.py) שבענף זה: Auto, GPT-6 Luna, GPT-6.1 Sol, Claude Haiku 4.5, Sonnet 5.5 ו־Opus 5.5. זו תצוגה סטטית להמחשת הבחירה, ללא המלצת איכות, זמינות חיה, תמחור או חיבור לספק. המיפוי העתידי לתפקידי המוצר יהיה translator / semantic_reviewer / chapter_qa.

## הספר הוא הכרטיס

איור הספר שהיה מעל הפרטים הוסר מכרטיסי חלופה א. כעת כריכה מפוקסלת, שדרה וחתך דפים מקיפים את שם הספר, המצב, המטא־נתונים והפעולות. כל המידע הוא HTML גמיש על רקע קלף; המסגרת גדלה עם התוכן. הכותרת מופיעה פעם אחת, ללא חיתוך או מגבלת שורות. כותרת ארוכה ומחרוזת בלתי שבירה נבדקו במפורש.

נוספו חתול ספרייה מקורי עם ספל קפה, הכותרת ״ספרים ישנים. רעיונות בלי אבק.״, ״אין קנסות על קריאה איטית״ והערות קטנות לכל ספר. ההומור נשאר בשולי החוויה; הפעולות עצמן נשארות ישירות. העדפת צמצום האיורים מסירה חתול ומסגרות בלי להסתיר מידע או את חיווי המפתח. תנועת הכרטיס מכבדת צמצום תנועה.
