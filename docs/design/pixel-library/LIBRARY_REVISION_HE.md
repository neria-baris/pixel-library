# הספרייה — ליטוש לפי משוב, 15.10.2026

חלופה א נקראת כעת **הספרייה**. זהו המשך ליטוש של אב הטיפוס שנבחר, בענף `design/pixel-library-prototypes`, ללא שילוב במוצר או ב־main. הפלטה הקיימת נשמרה.

| המשוב | השינוי |
| --- | --- |
| החיצים אינם נעימים | כפתורי מעבר עם המילים ״הקודם״ ו״הבא״, קישורים עם שמות פעולות, ופתיחה/סגירה עם פלוס ומינוס. |
| המחיקה אינה מופיעה | כפתור ״מחיקה״ עם סמל פח מופיע בכל כרטיס ספר, גם במובייל. אישור מציג את שם הספר; אפשר להשאירו, לסגור עם Escape או לבטל את המחיקה לאחר מכן. |
| ידית הפליז אינה מתאימה למסילה | ידית ירוקה מט, מסילה וקצוות מרובעים באותה שפה. נשמרו גרירה, מקלדת, תחנות בחירה ושדה מספר מדויק. |
| השם והאיור העליון אינם מתאימים | שם ישיר, ״הספרייה״, ואיור פיקסל מקורי ומאופק של שדרות ספרים ישנים. איורים קטנים חוזרים הוסרו מהסרגל ומסיכום הבחירות. |

המחיקה משנה רק את אוסף הדוגמה בזיכרון הדף. היא אינה מוחקת קובץ במחשב. הספירה, החיפוש, הסינון, המשך הקריאה והמצב הריק מתעדכנים; ביטול משחזר את הספר האחרון שהוסר. רענון מחזיר את כל הדוגמאות. אין שירות חיצוני, אחסון קבוע או קריאת תוכן קובץ.

[דוח ממוקד](library-revision/verification.json).

גם כל 82 בדיקות הזרימה הקיימות עברו מחדש בשתי החלופות. [דוח זרימות](library-revision/flow-verification.json). הצילומים הסינתטיים נסקרו חזותית. לאחר הריצה קוצרה כותרת דיאלוג המחיקה ל״מחיקת ספר״ וצולם ונבדק הדיאלוג שוב ב־320 פיקסלים. אין טענה לבדיקה במכשיר מגע אמיתי, Firefox, נגישות מלאה או רגרסיית מנוע התרגום; קוד המוצר לא שונה.

שחזור כאשר שרת התצוגה ב־8817 ו־Chrome ייעודי עם CDP ב־9332 פעילים:

```powershell

powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/design/test_pixel_library.ps1
```

בדיקות וצילומים משתמשים רק בספרי הדוגמה. החוזה הוא `audit/contracts/ux_library_revision.md`; יומני הביצוע והשערים נשמרים ב־audit. המימוש בוצע ישירות ב־Codex בהתאם לאישור המשתמש; לא הופעלו בונים חיצוניים או ספקי ריצה. שימוש ועלות מנוי אינם מדידים כאן. הגרסה מקומית בלבד.
