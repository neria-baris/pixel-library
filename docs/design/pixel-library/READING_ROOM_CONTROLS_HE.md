# חדר הקריאה — פקדים שנוח לאחוז בהם

15.10.2026 · UX-READING-CONTROLS · ליטוש אב הטיפוס שנבחר, בהתאם להבהרת המשתמש. ללא שילוב באפליקציה העובדת או ב־main.

פקדי ברירת המחדל היו עדינים מדי לעולם הספרייה. הידיות החדשות נראות כאביזרי פליז קטנים, עם אזורי לחיצה גדולים וברורים. הערכים ומשמעותם נשמרו.

- **מחוונים:** מסילה בעובי 12px, מילוי בכיוון RTL, ידית מרובעת 32px עם חריצי אחיזה ואזור גרירה בגובה 56px. נשמר input מקורי עם מקלדת וגרירה.
- **דרגות:** רמת בדיקה ומאמץ נבחרות גם בתחנות לחיצה בגובה 56px, עם מצב נבחר מובחן. במאמץ מופיעים אחוזי 10/20/30; אין שינוי במדיניות הלמידה.
- **מספרים:** התקציב ניתן להקלדה מדויקת, ולצדו כפתורי ‎+/− בגודל 48px לפחות במקום חצי spinner זעירים. לחיצה משנה דולר אחד ושומרת אגורות, בלי לחרוג מהגבולות. גם גודל הטקסט מקבל כפתורי הגדלה והקטנה.
- **מעבר ופתיחה:** ״הקודם״ ו״הבא״ מחליפים חצים בודדים, לצד סמלים פיקסליים עבים. פתיחת הגדרות ופסי הגלילה קיבלו את צבעי הקלף והפליז. חצי פסי הגלילה הוסרו ב־WebKit/Chromium.
- **מובייל:** התקציב המדויק נפרס בשורה מלאה; ספירת המקטעים מופיעה מעל שני כפתורי המעבר. תוויות ומצב נבחר נשארים גלויים.

שכבת העיצוב וההתנהגות נטענת רק ב־a.html (`reading-room.css/js`). hook יחיד ברינדור המשותף מחדש אותה אחרי ניווט. מנגנון המצבים ופקדי הקלט המקוריים נשמרו; חלופה ב נשארת כבסיס להשוואה. אין שליחת מידע, קריאות מודל או שינוי בקוד המוצר.
